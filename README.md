# Home Assistant Community Add-on: Jackett

[Jackett](https://github.com/Jackett/Jackett) add-on for Home Assistant.

This repository contains the Home Assistant add-on definition and its container build configuration.

## Installation

Add this repository to the Home Assistant Add-on Store, then install **Jackett**.

## Development

The add-on is built for `aarch64` and `amd64` by GitHub Actions.
